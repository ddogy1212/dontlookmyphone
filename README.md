# 내 폰을 보지 마 📱

안드로이드용 로컬 프라이버시 알림 앱입니다.

- 선택한 시간(분) 동안 보호 모드 활성화
- 보호 모드에서 앱 아이콘을 누르면 접근 시각을 기록
- 카메라 권한이 허용되어 있고 화면에서 촬영을 안내한 경우 전면 카메라 사진을 로컬 저장
- 2분간 `내 폰을 보지 마` 전체화면 경고(화면 켜짐 유지)
- 실행 기록과 사진은 기기 내 앱 전용 저장 공간에만 저장되며 업로드하지 않음

주의: 잠금화면 해제 자체를 감지하는 앱이 **아닙니다**. Android 보안 모델상 홈 버튼이나 시스템 UI를 강제로 차단할 수 없습니다. 개인정보 보호와 관련 법규를 준수해 사용하세요.

## APK 설치

[Actions 탭](../../actions/workflows/android.yml)에서 가장 최신의 성공한 `Build Android APK` 실행을 열고, 아래의 `dontlookmyphone-debug-apk` 산출물을 내려받아 ZIP 안의 APK를 설치하세요.

처음 실행할 때 카메라 권한을 허용하면 촬영 기능을 사용할 수 있습니다. **감시 시작**을 누르면 앱이 닫히고, 지정 시간 이내에 아이콘을 다시 눌렀을 때 기록/촬영이 시작됩니다.

## 개발

Android Studio에서 프로젝트를 열어 빌드할 수 있습니다. JDK 17, Android SDK 36를 사용하며 GitHub Actions에서 debug APK를 빌드합니다.

## 데이터 처리

사진은 앱의 private files 디렉터리에 저장됩니다. 네트워크 권한이 없고, 기록 화면에서 전체 삭제할 수 있습니다. 앱 삭제 시 기록과 사진도 삭제됩니다.
