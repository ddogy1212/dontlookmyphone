# afk · Direct Camera

**Android 전용 개인 휴대폰 보호용 로컬 앱**

## 동작

1. 사용자가 afk에서 **앱 사용정보 접근**, **다른 앱 위에 표시**, 카메라 권한을 허용합니다.
2. 보호 시간을 분 단위로 지정하고 보호를 시작합니다.
3. 보호 중 카카오톡 등 다른 앱이 열렸다는 사용 기록 이벤트가 감지되면 앱 이름과 시간을 로컬 기록에 남깁니다.
4. Android가 백그라운드 화면 전환을 허용하면 **경고 화면 없이 전면 카메라 화면으로 바로 전환**합니다.
5. 전면 카메라 **미리보기가 보이고 촬영 버튼을 눌렀을 때만** 사진이 저장됩니다. 아무 사진도 찍지 않고 나갈 수도 있습니다.
6. 기기의 OS 정책으로 자동 전환이 차단될 경우 **알림을 눌러 셀카 화면으로 이동**할 수 있습니다.
7. 지정 시간이 끝나면 감지가 종료됩니다.

## 중요한 사항

- **경고 화면 없음.** 다른 앱 실행만으로 몰래 사진을 촬영하지 않습니다.
- Android의 백그라운드 화면 실행 제한으로 모든 기기에서 자동 전환을 보장할 수 없습니다. 알림 바로가기를 사용하세요.
- 카메라 사진과 접근 기록은 휴대폰 내 앱 전용 저장소에만 보관되며 네트워크로 업로드하지 않습니다.
- 앱은 시스템 잠금 해제나 긴급 기능을 가로막지 않습니다.
- 기기 설정에 따라 배터리 최적화로 백그라운드 감지가 중지될 수 있습니다.
- 안드로이드의 강력한 사용 기록 접근 권한을 요청하므로, 본인 기기에서만 사용하세요.

## 설치

GitHub Actions의 성공한 [Build Android APK](../../actions/workflows/android.yml) 실행에서
`dontlookmyphone-debug-apk`을 내려받고 ZIP 안의 `app-debug.apk`을 설치하세요.

이 에디션의 앱 ID는 `com.kyubang.afk.directcam`이며, 기존 afk와 **다른 앱으로 설치**됩니다.
앱 아이콘 아래 표시는 **afk**입니다.

## 개발

Android Studio / Java 17 / compileSdk 36 / targetSdk 35 / CameraX.
