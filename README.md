# afk (안드로이드) 📱

**내 휴대폰을 다른 사람이 무단으로 사용하는 상황에 대한 로컬 경고 앱**입니다.

## 2.0 기능

- **시간 지정**: 1~1,440분 동안 보호 모드 활성화
- **다른 앱 실행 감지**: 앱 사용정보 접근 권한을 직접 허용하면 카카오톡, 인스타그램 등 다른 앱 실행 이벤트 확인
- **즉시 경고**: 다른 앱이 실행되면 `내 폰을 보지 마`라는 경고 창을 다른 앱 위에 2분 동안 표시
- **실행 기록**: 실행 앱 이름(일부 앱은 패키지명으로 표시), 시각을 기기 내부에만 저장
- **경고에서 셀카 카메라 열기**: 다른 앱 실행 감지 후 경고에 표시되는 버튼을 누르면 전면 카메라 프리뷰를 열고 잠시 뒤 사진을 로컬 저장합니다. afk 앱 자체를 열어도 같은 방식으로 촬영합니다.
- **기록 관리**: 기록/사진 조회와 전체 삭제
- **보호 모드 안내**: 서비스 동작 중 알림으로 알려주며 지정한 시간이 지나면 자동 종료
- **네트워크 통신 없음**: 촬영 사진과 기록은 서버로 전송하지 않음

## 사용 방법

1. [Actions](../../actions/workflows/android.yml)에서 성공한 최신 `Build Android APK`를 선택하고 `dontlookmyphone-debug-apk`을 다운로드합니다.
2. ZIP 파일에서 `app-debug.apk`를 추출한 후 안드로이드 휴대폰에 설치합니다.
3. **afk** 실행 후 **앱 사용정보 접근**과 **다른 앱 위에 표시** 권한을 허용합니다.
4. 원하는 보호 시간을 분 단위로 입력하고 **보호 시작**을 누릅니다. 처음 실행 시 카메라 권한도 허용할 수 있습니다.
5. 이제 카카오톡 같은 다른 앱을 열면 경고 화면이 뜨고 실행 시각이 기록됩니다. 경고 화면의 **셀카 카메라 열기**를 누르면 전면 카메라 화면이 열리고 촬영 후 경고 화면으로 전환됩니다.
6. 보호 모드 실행 중 알림을 누르면 관리 화면으로 이동하며, 기기 잠금 인증으로 기록 조회와 종료를 보호할 수 있습니다.

## 한계와 개인정보

- 잠금화면의 비밀번호 해제 자체는 감지하지 않으며, 다른 앱을 실행한 경우를 감지합니다.
- 다른 앱의 실행만으로 **몰래 사진을 촬영하지 않습니다**. 경고에서 카메라 열기 버튼을 누른 뒤 보이는 전면 카메라 화면에서만 촬영합니다. Android의 백그라운드 앱 실행/카메라 제한에 따라 이 동작은 사용자 조작이 필요합니다.
- 사용정보 이벤트는 Android 시스템 및 제조사의 정책, 배터리 최적화에 따라 일부 누락되거나 지연될 수 있습니다.
- 경고는 안드로이드 시스템 탐색, 긴급 기능, 강제 종료를 막지 않습니다.
- 안드로이드의 앱 사용정보 접근 권한은 강력한 권한이므로 신뢰할 수 있는 기기에서만 허용하세요.
- APK가 다른 debug 서명 키로 빌드되면 이전 앱 제거 후 새 앱 설치가 필요하며, 기존 로컬 기록은 삭제됩니다.

## 개발 환경

Android Studio · Java 17 · Android API 36 (targetSdk 35) · CameraX

코드는 오픈 소스로 저장소 내에서 확인할 수 있으며, GitHub Actions가 debug APK를 빌드합니다.

- 앱 고유 ID를 `com.kyubang.afk.selfie`로 변경해 기존 afk와 별도로 설치되도록 했습니다.
